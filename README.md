# 🎮 شهر شادی — بازی جهان‌باز دوبعدی موبایل

یک بازی جهان‌باز (Open World) دوبعدی و کاملاً فارسی برای اندروید که با **جاوا و کاتلین** و بدون هیچ کتابخانه خارجی ساخته شده است. مناسب همه سنین (۰ تا ۱۸ سال)، بدون خشونت و کاملاً آفلاین.

## 🛠 شروع سریع در اندروید استودیو

### مرحله ۱: باز کردن پروژه
1. **Android Studio** (نسخه Hedgehog به بالا ترجیحاً) را باز کن
2. از منو: `File → Open`
3. پوشه `ShahrShadi` را انتخاب کن و `OK` بزن
4. صبر کن تا **Gradle Sync** تمام شود (بار اول چند دقیقه طول می‌کشد چون وابستگی‌ها دانلود می‌شوند — اینترنت لازم است)

### مرحله ۲: گرفتن خروجی APK
- از منو: `Build → Build App Bundle(s) / APK(s) → Build APK(s)`
- بعد از اتمام، روی `locate` در پیام پایین صفحه کلیک کن
- فایل APK در این مسیر است:
  ```
  app/build/outputs/apk/debug/app-debug.apk
  ```
- فایل را به گوشی بفرست و نصب کن! 🎉

### خروجی Release (بهینه‌تر)
- از منو: `Build → Generate Signed App Bundle / APK`
- یک Keystore بساز (Create new...) و مراحل را دنبال کن

### اجرا روی گوشی با USB
1. در گوشی: `تنظیمات → گزینه‌های توسعه‌دهنده → اشکال‌زدایی USB` را فعال کن
2. گوشی را با کابل وصل کن
3. در اندروید استودیو دکمه سبز **Run ▶** را بزن

> **نکته:** اگر هنگام باز کردن پروژه درباره Gradle Wrapper سؤال شد، گزینه **Use recommended / OK** را بزن. JDK 17 لازم است که همراه اندروید استودیو نصب است.

## 💡 راهنمای پول درآوردن!

1. **پول جیبی روزانه**: هر روز از «بانک سپهر» ۳۰۰ تومان بگیر
2. **ماموریت NPC**: با شهروندها حرف بزن و «ماموریت داری؟» را بزن (۳۰۰ تا ۸۰۰ تومان)
3. **تاکسی رانی**: اول ماشین بخر (ارزان‌ترین ۱۵٬۰۰۰) → اداره مشاغل → تاکسی
4. **پیک موتوری**: موتور بخر (۴٬۰۰۰) → اداره مشاغل → پیک
5. **گارسونی**: وارد «رستوران زنجبیل» شو و با مدیر حرف بزن
6. **فروشندگی**: وارد «سوپرمارکت فراوان» شو و با مدیر حرف بزن

## 📂 ساختار کد

```
ShahrShadi/
├── app/src/main/java/com/persiancity/game/
│   ├── MainActivity.kt          ← منوی شروع (کاتلین)
│   ├── GameActivity.kt          ← اکتیویتی بازی (کاتلین)
│   ├── SaveManager.kt           ← ذخیره/بارگذاری JSON (کاتلین)
│   ├── SoundManager.kt          ← صداهای ساخته‌شده با کد (کاتلین)
│   └── game/                    ← موتور بازی (جاوا)
│       ├── GameView.java        ← قلب بازی: حلقه اصلی، ورودی، ذخیره
│       ├── GameThread.java      ← حلقه ۶۰ فریم
│       ├── World.java           ← دنیا، تایل‌ها، برخورد
│       ├── CityBuilder.java     ← نقشه شهر بزرگ
│       ├── Interior.java        ← داخل رستوران و سوپرمارکت
│       ├── Player.java          ← بازیکن
│       ├── Npc.java             ← شهروندها
│       ├── Vehicle.java         ← ماشین و موتور + ترافیک شهری
│       ├── JobSystem.java       ← ۴ شغل
│       ├── MissionSystem.java   ← ماموریت‌ها
│       ├── ShopSystem.java      ← فروشگاه‌ها
│       ├── Dialogues.java       ← دیالوگ‌های فارسی
│       ├── DayNight.java        ← چرخه روز و شب
│       ├── MiniMap.java         ← مینی‌مپ
│       ├── UIManager.java       ← HUD و منوها
│       ├── SpriteLib.java       ← رسم کارتونی همه چیز با کد
│       ├── Camera.java, Joystick.java, Building.java, Entity.java, G.java
└── app/src/main/res/            ← رابط منوی اصلی، آیکون‌ها
```

**تقسیم زبان‌ها:** موتور بازی و منطق گیم‌پلی با **جاوا**؛ اکتیویتی‌ها، ذخیره‌سازی و صداها با **کاتلین** — همکاری دو زبان در یک پروژه!

## ❓ رفع اشکال

| مشکل | راه‌حل |
|---|---|
| Gradle Sync خطا داد | اینترنت را چک کن؛ `File → Sync Project with Gradle Files` |
| "Unsupported class file major version" | اندروید استودیو را به‌روز کن (JDK 17 لازم است) |
| فارسی به‌هم‌ریخته است | فایل‌ها با کدگذاری UTF-8 ذخیره شده‌اند؛ نرم‌افزار بازکننده را روی UTF-8 بگذار |
| بازی روی شبیه‌ساز کند است | از یک گوشی واقعی استفاده کن یا شبیه‌ساز را با RAM بیشتر بساز |
| بازی موقع «شروع بازی» می‌پرد بیرون | نسخه قدیمی را اول **حذف نصب (Uninstall)** کن، بعد `Build → Rebuild Project` بزن و APK تازه را نصب کن. APK قدیمی با کد قبلی ساخته شده و با نسخه جدید فرق دارد |
| Build خطای کامپایل داد | `Build → Clean Project` و بعد `Build → Rebuild Project` بزن |
