# شهر شادی — Shahr-e Shadi v2.2 🚂

بازی ۲بعدی اوپن‌ورلد فارسی برای اندروید (۰-۱۸ سال) — Java Engine + Kotlin UI، بدون کتابخانه خارجی

## نسخه ۲.۲ (versionCode 6) — با قطار شهری!

### قابلیت‌ها
- **شهر بزرگ ۱۴۰×۱۰۰ تایل** با کمربندی قابل رفت‌وآمد و ۵ خیابان داخلی
- **🚂 قطار شهری (جدید!)**: ریل دور شهر + ایستگاه قطار + لوکوموتیو با ۳ واگن + دود دودکش + بوق نزدیک ایستگاه
  - بلیط ۲۰۰ تومانی: یک دور کامل سفر مسافری
  - خرید قطار ۵۰,۰۰۰ تومان: خودت راننده باش (اهرم = گاز/ترمز)
- ترافیک واقعی: ۱۸ خودرو، تصادف → دود → محو ۳ ثانیه → ظاهر شدن جای دیگر
- برخورد بازیکن با خودروها و قطار (رد شدن ممکن نیست)
- «نگاه کن»: کلیک = باز، لمس بیرون باکس = بسته
- رستوران/کافه/سوپرمارکت با غذای واقعی + شیفت گارسون و صندوق
- ذخیره خودکار هر ۲۰ ثانیه + ادامه همیشگی بازی + صفحه ساخت شخصیت (اسم + دختر/پسر)
- مینی‌مپ: خانه، رستوران، سینما، بیمارستان، ایستگاه قطار، قطار متحرک، هلیکوپتر
- سینما: صندلی قرمز + ۳ فیلم انیمیشنی واقعی (ماشین/ماهی/موشک)
- هلیکوپتر پرواز آزاد + باغ‌وحش با ۶ حیوان + آبشار پارک
- جاده زیبا: خط‌چین، خط عابر، چاهک، موج آب
- صدای کامل: موسیقی ۸ میزانی، افکت‌ها، موتور، بال‌زنی هلی، بوق قطار (AudioTrack — بدون فایل)

## نصب
1. Android Studio → Open → پوشه `ShahrShadi`
2. صبر برای Gradle Sync (نیاز به اینترنت)
3. Run ▶️ روی گوشی یا شبیه‌ساز

## فنی
- minSdk 24 | targetSdk 34 | AGP 8.5.2 | Kotlin 1.9.24 | Java 17
- Canvas 2D + SurfaceView + AudioTrack — بدون کتابخانه خارجی
- ۲۲ فایل Java + ۵ فایل Kotlin — کامپایل‌تأیید شده (۰ خطا)
