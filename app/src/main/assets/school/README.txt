پوشهٔ صداهای آموزش مدرسه 🏫
=============================

فایل‌های صدایی که می‌فرستی را با این اسم‌ها همین‌جا بگذار تا خودکار پخش شوند:

آموزش اعداد (۱۱ فایل):
  assets/school/numbers/1.mp3  → صدای «صفر»
  assets/school/numbers/2.mp3  → صدای «یک»
  assets/school/numbers/3.mp3  → صدای «دو»
  ...
  assets/school/numbers/11.mp3 → صدای «ده»

آموزش الفبا (۳۲ فایل — به ترتیب الفبا از ا تا ی):
  assets/school/letters/1.mp3  → صدای «ا»
  assets/school/letters/2.mp3  → صدای «ب»
  assets/school/letters/3.mp3  → صدای «پ»
  ...
  assets/school/letters/32.mp3 → صدای «ی»

نکته‌ها:
• فرمت mp3 یا ogg یا wav فرقی ندارد، فقط پسوند را درست بنویس (اگر ogg فرستادی بگو تا پسوندها را عوض کنم).
• اگر بعضی فایل‌ها را نداری، اشکالی ندارد — بازی بی‌صدا از آن کارت رد می‌شود و خطا نمی‌دهد.
• می‌توانی تصویر کارت‌ها را هم بفرستی (png)؛ بعداً با همین روش اضافه‌شان می‌کنم:
  assets/school/pictures/numbers/1.png و assets/school/pictures/letters/1.png
